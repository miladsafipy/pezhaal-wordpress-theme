# Pezhaal — Custom WordPress Theme

A custom RTL WordPress theme for Pezhaal, a Persian
handmade arts and crafts online store built with WooCommerce.

## Project Overview

Pezhaal is a custom theme developed to create a modern,
responsive shopping experience for Persian-speaking users.

## Features

- Right-to-left (RTL) layout and Persian typography
- Custom theme structure using PHP templates
- WooCommerce product integration
- Custom product card components
- Responsive navigation and page layouts
- Custom homepage sections
- Reusable CSS design system
- JavaScript interactions

## Tech Stack

- WordPress
- WooCommerce
- PHP
- HTML
- CSS
- JavaScript
- Git and GitHub

## Development Environment

- Local WordPress installation
- XAMPP
- Visual Studio Code

## Installation

1. Install WordPress locally.
2. Install and activate WooCommerce.
3. Clone this repository into:

   `wp-content/themes/pezhaalTheme`

4. Activate the Pezhaal theme from the WordPress dashboard.
5. Configure WooCommerce pages and theme settings as needed.
